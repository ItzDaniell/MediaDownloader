# Arquitectura - Media Downloader

## Descripción General

Media Downloader es una aplicación WPF que proporciona una interfaz gráfica para descargar contenido multimedia desde YouTube y X (Twitter) usando yt-dlp como backend.

## Componentes Principales

### 1. **MainWindow.xaml / MainWindow.xaml.cs**
- **Responsabilidad**: Interfaz de usuario
- **Funcionalidades**:
  - Entrada de URL
  - Selección de formato (MP3/MP4)
  - Selección de carpeta de destino
  - Botón de descarga
  - Visualización de estado y progreso

**Elementos de UI**:
- `UrlTextBox`: Campo para introducir URLs
- `FormatComboBox`: Selector de formato
- `BrowseFolderButton`: Botón para elegir carpeta
- `DownloadButton`: Botón principal de descarga
- `StatusTextBlock`: Visualización de estado
- `ProgressBar`: Indicador de progreso
- `PathTextBlock`: Ruta de descarga actual

### 2. **DownloadService.cs**
- **Responsabilidad**: Lógica de descargas
- **Métodos Públicos**:
  - `DownloadFromYoutubeAsync(url, format)`: Descarga desde YouTube
  - `DownloadFromXAsync(url, format)`: Descarga desde X
  - `IsValidUrl(url)`: Valida si la URL es soportada
  - `GetPlatform(url)`: Identifica la plataforma
  - `GetDownloadPath()`: Obtiene ruta de descargas

- **Métodos Privados**:
  - `BuildYtDlpArguments(url, format)`: Construye argumentos para yt-dlp
  - `ExecuteYtDlpAsync(arguments)`: Ejecuta yt-dlp en proceso separado

- **Eventos**:
  - `StatusChanged`: Se dispara cuando cambia el estado

### 3. **App.xaml / App.xaml.cs**
- **Responsabilidad**: Configuración de la aplicación
- **Contiene**:
  - Punto de entrada de la aplicación
  - Estilos globales
  - Recursos compartidos

## Ciclo de Vida de la Aplicación

1. **Inicio**
   - App.xaml.cs: Initializa la aplicación WPF
   - MainWindow.xaml se carga

2. **Inicialización de MainWindow**
   - InitializeApplication() se ejecuta
   - DownloadService se crea con ruta por defecto
   - Se suscribe a eventos de StatusChanged
   - Se actualiza la visualización de ruta

3. **Interacción del Usuario**
   - Usuario ingresa URL
   - Usuario selecciona formato
   - Usuario hace clic en Descargar

4. **Proceso de Descarga**
   - Validación de URL
   - Identificación de plataforma
   - Construcción de argumentos de yt-dlp
   - Ejecución de proceso asincrónico
   - Actualización de UI con estado

5. **Finalización**
   - Se muestra mensaje de éxito/error
   - Se habilitan controles nuevamente
   - Archivo descargado está en carpeta de destino

## Dependencias Externas

### Runtime
- **.NET 8.0 Runtime**
- **yt-dlp**: Herramienta CLI para descargas
  - Maneja la descarga real
  - Gestiona formatos y codificación
  - Soporta múltiples plataformas

### Build
- **Visual Studio 2022** o superior (recomendado)
- **.NET 8.0 SDK**

## Configuración

### Ruta de Descarga por Defecto
```
C:\Users\[NombreUsuario]\Downloads\MediaDownloader
```

### Formato de Archivo Descargado
```
%(title)s.%(ext)s
Ejemplo: "Mi Video Descargado.mp3"
```

### Timeouts
- **Descarga**: 5 minutos (300,000 ms)
- Configurable en `ExecuteYtDlpAsync()`

## Manejo de Errores

La aplicación maneja varios tipos de errores:

1. **URL Inválida**: Muestra mensaje de validación
2. **Plataforma no soportada**: Alerta al usuario
3. **Fallos de yt-dlp**: Muestra error de proceso
4. **Errores de Sistema**: Excepción general capturada

## Seguridad

- Las URLs se validan antes de procesarlas
- El proceso de yt-dlp se ejecuta sin shell
- Se crea un nuevo proceso para cada descarga
- Timeout de 5 minutos para evitar procesos huérfanos

## Rendimiento

- **UI responsiva**: Uso de async/await
- **Sin bloqueos**: MainWindow no se congela durante descarga
- **Procesos separados**: yt-dlp ejecuta en thread separado
- **Uso de memoria**: Mínimo, sin caching de archivos

## Extensibilidad

Para agregar nuevas plataformas:

1. Actualizar `IsValidUrl()` con nuevo dominio
2. Agregar condición en `GetPlatform()`
3. Crear método `DownloadFrom[Plataforma]Async()` en DownloadService
4. Conectar en MainWindow.DownloadButton_Click()

Ejemplo:
```csharp
if (platform == "Instagram")
{
    success = await _downloadService.DownloadFromInstagramAsync(url, format);
}
```
